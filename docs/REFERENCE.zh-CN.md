# Sinheo-Comfyui-PromptLibrary · Sinheo 加载文本

**仓库名 / Repository**：`Sinheo-Comfyui-PromptLibrary`（GitHub 与安装目录同名）。

把「提示词管理.html」搬进 ComfyUI 的**文字版图库选择器**，界面按 Goohai 加载图库节点的紧凑样式重做：
上面两行是勾选菜单和随机开关，中间一大块是**可直接编辑的文本框**，底部是「＋ 添加到 / 选择小类 / 生成 / 复制」按钮。节点名统一用 `Sinheo` 前缀。

**插件和数据彻底分开**：代码在 `custom_nodes/`，提示词全在 `models/`，直接用 Windows 资源管理器改 TXT 就能加词，不用重启 ComfyUI。

---

## 1. 安装

```
ComfyUI/
├── custom_nodes/
│   └── Sinheo-Comfyui-PromptLibrary/          ← 本插件
│       ├── __init__.py           节点定义 + HTTP API
│       ├── sinheo_core.py        扫描 / 生成 / 编辑 / 导入导出
│       ├── web/sinheo.js         节点面板、勾选菜单、管理弹窗、导出/添加到勾选弹窗
│       └── web/sinheo.css
└── models/
    └── Sinheo/
        └── prompts/             ← 你的词库（示例内容从 Sinheo_prompts_starter 复制）
```

重启 ComfyUI，右键 / 搜索 **`Sinheo 加载文本`**（分类 `Sinheo / 文本`）添加节点。
输出的 `prompt` 是 STRING，直接连 `CLIP Text Encode`；`detail` 是本次抽词明细。

> 旧版 `ComfyUI-PromptLibrary` 已改名为 `ComfyUI-PromptLibrary.disabled`（ComfyUI 会跳过 `.disabled` 目录），
> 它的 `models/prompt_library` 数据保留未动。

## 2. 词库目录约定（只有两级）

```
models/Sinheo/prompts/
│   _order.json                     手动排序结果（插件自动维护，可以不管）
│   随便一个.txt                    根级 TXT → 归入虚拟大类「未分组」
│
├── 上衣/                           大类（一级文件夹）
│   ├── 甜美.txt                    小类就是一个 TXT，一行一条提示词
│   ├── 可爱.txt
│   └── 酷酷的.txt
│
├── 服饰/                           另一个大类
│   ├── 上衣.txt
│   ├── 下装.txt
│   └── 连衣裙.txt
└── ...
```

规则：

- **一个小类 = 一个 TXT**，不再有小类文件夹、也不再往小类里塞多个 TXT。管理界面里选中一行就直接编辑那一个 TXT。
- 一行一条提示词；空行忽略，`#` 开头是注释；同文件内自动去重。
- 文件夹名前面加 `01_` `02_` 只影响**初始顺序**，界面上会去掉前缀显示（例如 `01_甜美` 显示为 `甜美`）。
- **真正的顺序靠界面里的 ▲▼ 手动排**，不依赖文件名，排完可以「💾 设为默认顺序」写进 `_order.json` 让新节点继承。
- 改完 TXT 不用重启，节点每次执行都会重新扫描；也支持 `extra_model_paths.yaml` 追加 `sinheo_prompts` 只读目录。

### 旧三级目录会自动展平

早期版本的 `上衣/甜美/提示词.txt` + `上衣/甜美/0.txt` 这种结构，插件首次扫描时会**自动合并**成 `上衣/甜美.txt`（词条一条不丢），原小类文件夹整份备份到 `models/Sinheo/prompts/.backup/migration-<时间戳>/` 后删除。也可以点管理弹窗调用 `POST /sinheo/migrate` 手动触发。

## 3. 节点长什么样 / 怎么用

| 区域 | 作用 |
| --- | --- |
| **`◀ 类型 ▾`** | 打开**勾选菜单**（代替 Goohai 的下拉菜单）。行尾显示已选小类数。 |
| **`◀ 随机`** | 总开关。**关**：节点只输出文本框里的文字；**开**：每次运行按勾选菜单自动重新随机抽词，**忽略文本框**。 |
| **`⚙ 词库管理 · N 个小类 / M 条`** | 打开管理弹窗；右侧 `↻` 重新扫描词库。 |
| **大文本框** | 可直接编辑的提示词文本。新节点会按菜单顺序自动填入一份初始提示词；随机关闭时它就是要输出的最终文本。 |
| **`＋ 添加到` / `🎯 选择小类 ▾` / `生成` / `复制`** | 底部**一行**四个按钮，见下。面板不再显示常驻状态说明文字，操作结果短暂显示在按钮上，详细信息可悬停按钮查看。 |

> 版式调整（1.2.1）：类型行 / 随机行 / 词库管理条 / 文本框 / 按钮的字号与高度整体放大，底部强制单行不换行；四个按钮顺序为 `＋ 添加到 → 🎯 选择小类 ▾ → 生成 → 复制`。

### 随机开关关闭时（默认）

- 文本框**可以直接改**，改什么就输出什么；前缀 / 后缀 / 词库 / 随机都不再参与运算。
- **`生成`**：按当前勾选菜单**手动随机抽一批**提示词填进文本框。改完勾选菜单后要点一下「生成」才会更新文本；生成的文字同样可以手动修改。
- **`复制`**：把文本框里的提示词复制到剪贴板。
- **`＋ 添加到`**：把当前文本框里的提示词**按行追加**到你选中的小类 TXT，收藏进词库。
- 文本框内容随工作流一起保存（存在隐藏的 `manual_text` 输入里）。

### 「＋ 添加到」怎么收藏提示词

- 右边的 **`🎯 选择小类 ▾`** 会弹出一个可搜索的**勾选弹窗**：勾大类 = 勾它下面全部小类，也能单独勾某几个小类，支持全选 / 全不选 / 反选。
- 弹窗里 `✓ 确定选择` 只记住目标；`＋ 添加到选中（N）` 则记住并**立刻写入**。之后直接点节点上的 `＋ 添加到` 就能重复添加到同一批目标，按钮旁会显示「已选 N 类」。
- 写入是**只追加**：原 TXT 的 `#` 注释、原有顺序、行尾格式全部保留，已存在的词条自动跳过（不会重复）。一行算一条；如果文本框里是多行（批量生成），就一次加多条。
- 随机模式下也能用：此时收藏的是**本次运行刚产生的随机提示词**（很适合抽到满意的组合就存起来）。

### 随机开关打开时

- 每次排队运行都**重新按勾选菜单随机抽词**，文本框里的文字**不参与输出**。
- 文本框变成**只读**，运行后显示本次实际随机生成的结果；你原来写的文字不会丢，关掉随机就原样恢复。
- **`复制` 仍然可用**，复制的就是文本框里显示的本次运行结果（先运行一次工作流；没运行前会提示无内容）。
- **`生成` 停用**（文本框此时不参与输出，手动抽词没有意义）；`＋ 添加到` 仍可用。
- 节点缓存指纹为 NaN，所以每次排队都会真正重新执行。

> 一句话：**关 = 手动定稿**（文本框说了算），**开 = 自动抽卡**（词库说了算）。

### 勾选菜单

- **`Filter list`**：搜索大类、小类、具体提示词（仿 Goohai 的搜索框）。
- **大类行**：`☑` 勾整组，`▾` 折叠，`🎲` 让这个大类每次运行**随机抽 1 个已勾选的小类**，▲▼ 调整大类顺序。
- **小类行**：`☑` 单独勾「甜美」「酷酷的」；点名字展开可勾**具体提示词**（不勾 = 整个小类参与；勾 1 条 = 固定；勾多条 = 从中随机抽 1 条），▲▼ 调整小类顺序。
- **每个小类永远只贡献 1 条关键词**（「全部拼接」已移除）：勾了词条就从勾的里面抽 1 条，没勾就从整个小类抽 1 条。同类拼一长串反而看不出是什么，所以不做拼接。
- **循环排序**：顶部的大类/小类按 ▲ 会**自动绕到最底部**，底部的按 ▼ 会**自动绕回最顶部**，不用一路点到底。
- **底部工具**：全选 / 全不选 / 反选 / 刷新（原先的「🎲 随机勾选」已移除，勾选完全由这个菜单决定）。
- **`⚙ 拼接设置`**：分隔符、前缀、后缀、一次生成条数（作用于「生成」按钮和随机模式）。

> ComfyUI 里提示词先后顺序会影响权重，所以**输出顺序严格等于勾选菜单从上到下的顺序**。

### 管理弹窗

- `＋大类` / `＋小类`：建文件夹 / 建一个 TXT 小类。
- 左侧树选小类 → 右侧直接编辑那一个 TXT，一行一条；`💾 保存` / `🗑 删除小类`（**删除前自动备份**到 `.backup/<时间戳>/`）。
- 大类、小类行的 ▲▼ 与勾选菜单同步，也是循环排序；`🗑` 可删整个大类（同样备份）。
- `📥 导入 TXT/ZIP`：旁边的**下拉菜单**选择导入到哪个大类（含「未分组」和「＋ 新建大类…」）；「提示词管理.html」导出的 ZIP 可以直接导入，ZIP 里的三级路径会自动展平成 `大类/小类.txt`。
- `📤 导出 ZIP`：先弹出**勾选界面**，可按大类整组勾、也可只勾某几个小类，支持全选/全不选/反选/搜索，确认后只打包勾中的 TXT（含 `_order.json` 的顺序子集）。
- `💾 设为默认顺序`：把当前节点菜单的顺序写进 `_order.json`，以后新建的节点继承这个顺序。
- `✕ 关闭` / `Esc` / 点弹窗外空白处都能关闭。

## 4. 随机怎么工作

**先说清楚随机的范围**：`随机` 不是「整个词库随便抽一串」，而是**只在类型菜单里已勾选的选项内部抽**。

1. 先看大类：`☑` 关掉的大类整个跳过；开了 `🎲` 的大类，运行时从**该大类已勾选的小类**里随机挑 1 个（默认 pick=1）。
2. 再看小类：`☑` 关掉的小类跳过。每个参与的小类**只出 1 条**——你在这个小类里勾了具体词条，就从勾的里面抽 1 条；没勾，就从这个小类全部词条里抽 1 条。
3. 最后按勾选菜单从上到下的顺序，用分隔符拼接；前缀 / 后缀 / 手写补充是**固定文本**，不参与随机。

所以「没勾的头发、上衣」永远不会被随机到。随机关闭时则完全不抽，按菜单顺序取每个小类的第一条（可复现）。

| 设置 | 随机 关 | 随机 开 |
| --- | --- | --- |
| 运行时输出 | 文本框里的文字，原样输出 | 每次重新从**已勾选的小类**随机抽词，文本框忽略 |
| `生成` | 可用（手动抽一批填进文本框） | 停用 |
| `复制` | 可用（复制文本框） | **可用**（复制本次运行产生的提示词） |
| `＋ 添加到` | 可用（收藏文本框内容） | **可用**（收藏本次随机结果） |
| 文本框 | 可编辑 | 只读，显示本次随机结果；原文保留 |
| 大类 `🎲` | 该大类下所有已勾小类都输出（各 1 条） | 该大类每次**随机挑 1 个**已勾小类输出 |

> 一句话：**关 = 手动定稿**（文本框说了算），**开 = 自动抽卡**（勾选菜单说了算）。

## 5. 从旧 HTML 迁移

1. 打开 `提示词管理.html` → 内容库 → **导出 ZIP**。
2. ComfyUI 里节点上点 `⚙ 词库管理` → 在「导入到」下拉里选一个已有大类，或选 `＋ 新建大类…` → `📥 导入 TXT/ZIP`。
3. 回到节点点一下 `生成`，把新导入的词抽进文本框。

ZIP 内路径统一规范成两级：`costume/上衣.txt` → `costume/上衣.txt`（选了目标大类则 → `目标大类/上衣.txt`）；扁平的 `上衣.txt` → `未分组/上衣.txt`；三级的 `上衣/甜美/提示词.txt` → `上衣/甜美.txt`。

## 6. HTTP API（供二次开发）

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/sinheo/library` | 扫描词库，返回 groups / categories / rel / order |
| POST | `/sinheo/generate` | `{config, random}` → `{text, detail, empty}`，给「生成」按钮 / 初始填充用 |
| POST | `/sinheo/save` | `{rel, content, merge}` 保存一个小类 TXT |
| POST | `/sinheo/create` | `{kind: group\|category, ...}` 新建大类 / 小类 TXT |
| POST | `/sinheo/append` | `{rels: [小类 rel], text}` 把提示词按行追加到勾中的小类 TXT（去重、保留注释） |
| POST | `/sinheo/delete` | `{rel}` 删除并备份 |
| POST | `/sinheo/order` | `{groups, categories}` 保存默认顺序 |
| POST | `/sinheo/import` | multipart：`file` + `merge` + `group`（大类 id 或空） |
| GET | `/sinheo/export` | 下载整个词库 ZIP（兼容旧调用） |
| POST | `/sinheo/export` | `{selection: [大类/小类 id]}` → 只打包勾中的部分 |
| POST | `/sinheo/migrate` | 手动把旧三级目录展平成两级 TXT（带备份） |

所有写入路径都做了越界校验（`..`、绝对路径、Windows 保留名、隐藏目录、超过两级的路径一律拒绝）。
